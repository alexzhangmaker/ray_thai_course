外部系统接入鉴权 (API Authentication)

外部应用访问词集与词库 CRUD 端点时，需携带以下两种鉴权头之一，或在 URL 追加 ?apiKey=...：

X-API-Key: thainotes_api_key_2026
// cURL 快速接入示例:
curl -H "X-API-Key: thainotes_api_key_2026" http://localhost:3002/api/collections
curl -H "Authorization: Bearer thainotes_api_key_2026" http://localhost:3002/api/words

标准 REST API 端点手册

支持词集管理、词条 CRUD、动态多例句维护与 SM-2 记忆算法评测打分。

GET /api/collections 获取全部词集单元列表 (附带词数与到期数)
POST /api/collections 创建新词集 (Body: name, description, tags)
GET /api/collections/:id 获取特定词集详情及其完整生词数组 (含多例句)
PUT /api/collections/:id 更新词集名称、描述或标签
DELETE /api/collections/:id 删除词集单元 (自动解绑关联映射)
POST /api/collections/:id/words 向指定词集添加生词条目 (支持 examples JSON 数组)
GET /api/words 全量词库检索 (?collectionId, ?dueOnly, ?search)
PUT /api/words/:id 更新具体生词信息、音标、释义与 examples 数组
DELETE /api/words/:id 删除单个生词条目及其所有关联记录
POST /api/dictation/review 提交导师听写评测 (Body: wordId, rating [0-5]) 自动更新 SM-2
GET /api/dictation/queue 获取听写会话队列 (?type=smart_due | collection | all)
